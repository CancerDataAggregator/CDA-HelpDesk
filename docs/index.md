# Re-Search made simple

<p style="font-size: 1.1rem; max-width: 640px; margin: 0 auto 24px;">No matter your coding comfort — from zero code to full API access — there's a way to CDA.</p>

<p style="max-width: 640px; margin: 0 auto 8px;">Think of Cancer Data Aggregator as one really, really enormous spreadsheet spanning six cancer data centers — GDC, PDC, IDC, GC, ICDC, and CTDC. Search by harmonized, common-language terms and get results back in a standard dataframe (or TSV) you can open in Excel, feed into a pipeline, or send to your favorite cloud resource.</p>
