# `tables()`

## NAME

`tables` — list all searchable CDA data tables

## SYNOPSIS

```python
tables()
```

## DESCRIPTION

Get a list of all searchable CDA data tables.

## RETURNS

`list of strings` — names of searchable CDA tables.
